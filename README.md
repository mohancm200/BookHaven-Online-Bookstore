# BookHaven - Online Bookstore

BookHaven is an online bookstore web application developed using PHP, MySQL, HTML, CSS and JavaScript.

## Features
- User registration and login
- Browse and discover books
- Shopping cart and wishlist
- Admin dashboard
- Sub-admin dashboard
- Book management
- MySQL database integration

## Technologies
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Local Setup
1. Install XAMPP.
2. Copy the project into the htdocs folder.
3. Start Apache and MySQL.
4. Create the online_bookstore database using phpMyAdmin.
5. Configure your local database connection.
6. Open http://localhost/apex-task4-bookstore/
